# 微调样本目录

本目录存放「模仿用户口吻」微调用的样本，运行时自动追加写入 `finetune.jsonl`（每行一条），
在设置页导出时下载。

## 样本格式

每行一个 JSON 对象（alpaca / LLaMA-Factory 兼容）：

```json
{"instruction":"以用户语气沟通","input":"有人问你在干嘛","output":"关你屁事。"}
```

- `instruction`：固定为 `以用户语气<动词>`，动词取自内置清单（沟通、聊天、互动、探讨、商榷、切磋、交际、汇报、报告、述职、总结、通报、叮嘱、交代、告诫）。
- `input`：由改写模型根据 `output` 反推的上下文。
- `output`：用户发送的原文。

## 采集开关

在 dsh 设置页的「输入重写」板块勾选「采集对话用于微调」后，每次发送（无论发送原文还是发送改写）都会把原文写入 `finetune.jsonl`。采集依赖一次额外的模型标注调用，会额外消耗 token。
