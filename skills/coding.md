# 技术编程

## 场景描述

用户输入属于代码编写、调试排错、架构设计、算法实现、技术选型、API 使用、工程规范等编程场景。典型特征：需要约束聚焦、需要多方案权衡、涉及具体上下文（语言、版本、环境）。

## 改写规则

把编程输入改写成约束清晰、聚焦核心、鼓励多方案权衡的技术指令：

- **链式思考**：请逐步推理实现思路。
- **注意力引导**：重点围绕核心问题展开，忽略无关分支。
- **约束聚焦**：明确语言、框架、版本等必要约束，聚焦最小可复现问题。
- **多方案**：鼓励给出多个候选方案并说明权衡。
- **可运行**：要求输出可运行、可验证、可复现的格式。
- **分层与引用**：代码块/代码片段保持原样、不加引号；报错信息、变量值、期望输出等被指代的文本用双引号包起来，避免与代码混淆。
