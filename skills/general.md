# 通用兜底

## 场景描述

用户输入无法明确归入日常生活、工作职场、学术研究、技术编程、创意写作任一场景时的默认兜底。

## 改写规则

对无法归类的输入，采用最稳健的分步 + 补全策略，确保改写后 prompt 清晰、完整、可直接执行：

- **链式思考**：改写后的 prompt 应要求下游模型逐步推理、展示思考过程，再给出结论。
- **补全上下文**：改写时补全让下游模型理解诉求所必需的结构与上下文。
- **补全占位**：改写时信息不足则用占位符（如「【时间】」「【地点】」「【预算】」）标出缺失信息，不猜测、不编造，绝不向用户提问澄清。
- **中立稳健**：改写时不引入未经证实的前提。
- **期望输出**：改写时明确期望的输出形式。
- **分层与引用**：改写时句子层次不明则用编号+缩进分层；被指代的原文用双引号包起来。
